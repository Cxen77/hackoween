# FLOODCAST presentation

Current judge deck: **FLOODCAST-v2-final.pdf** or editable **FLOODCAST-v2-final.pptx**.

The original `FLOODCAST.pdf`/`.pptx` files are the earlier V1 baseline (RMSE52,695.26, R²0.890945). They remain available for comparison and should not be presented as current scores.

PDF slides are image-backed renders; the PPTX retains editable text and the native metric table. Team details are pending user entry.
